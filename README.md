# Build with Claude

**An interactive learning portal for an eight-week coding bootcamp.**

## What is it?

Build with Claude is a web-based learning portal designed to help students work through a structured coding bootcamp, keep track of their progress, and complete assignments in one place.

The platform brings lessons, assignments, a writing workspace, and AI-assisted feedback together to support students as they learn and build.

## What can it do?

- **Organize learning:** Access an eight-week program with lessons and assignments organized by week.
- **Track progress:** See progress through the program and keep track of completed work.
- **Complete assignments:** Work on deliverables in an editor with preview and save options.
- **Get AI feedback:** Use Claude-powered feedback to review work and identify areas for improvement.
- **Support different learning paths:** Provide learning content tailored to different experience levels.
- **Review student work:** Give administrators tools to review submissions and monitor progress.

## Technology

The application is built with Next.js, React, TypeScript, and Supabase, with Anthropic's Claude API supporting AI-assisted feedback.

## Project goal

The goal is to bring structured learning, hands-on assignments, progress tracking, and AI feedback into one place, making a coding bootcamp easier to follow and manage.
